# SISTEMA DE IDENTIFICAÇÃO MÚLTIPLA - TOUR MANAGER

## TECNOLOGIAS IMPLEMENTADAS

### 1. QR CODE

- **Uso:** Visual, impressão, verificação manual
- **Alcance:** Requer câmera (0-2m)
- **Velocidade:** 1 item por vez
- **Custo:** R$ 0,05 por etiqueta impressa
- **Vantagem:** Universal, funciona sem tecnologia

### 2. NFC (Near Field Communication)

- **Uso:** Leitura por smartphone (Android/iOS)
- **Alcance:** 4-10cm
- **Velocidade:** 1 item por vez
- **Custo:** R$ 1-3 por tag adesiva
- **Padrão:** ISO 14443A / ISO 15693
- **Vantagem:** Qualquer celular moderno lê

### 3. RFID UHF (Ultra High Frequency)

- **Uso:** Leitura em massa, portais, pistolas
- **Alcance:** 1-10 metros
- **Velocidade:** 100+ itens por segundo
- **Custo:** R$ 2-5 por tag + leitor R$ 1.500-15.000
- **Padrão:** EPC Gen 2 (ISO 18000-6C)
- **Vantagem:** Operação industrial em larga escala

## ESTRUTURA DE DADOS

### Equipment Model

```python
qr_code_url      # String: URL da imagem QR Code
nfc_tag_id       # String: UID único da tag NFC (14 chars hex)
rfid_uhf_tag     # String: EPC da tag RFID UHF (formato GS1)
```

### Formato EPC (RFID UHF)

```
E2 + [Company:6] + [Item:8] + [Serial:6]
Exemplo: E20000010000000100AF32

E2         = Header EPC Gen 2
000001     = Company ID (1 em hex)
00000001   = Equipment ID (1 em hex)
00AF32     = Serial único
```

## INTEGRAÇÃO COM HARDWARE

### Portal RFID (Exemplo: Zebra FX9600)

**Configuração:**

1. Conectar leitor à rede (Ethernet/WiFi)
1. Configurar IP estático
1. Definir região (Brasil: 902-907.5 MHz)
1. Configurar potência de leitura (20-30 dBm)
1. Ativar modo “Tag Report” via HTTP

**Webhook Configuration:**

```
URL: https://seuapp.com/api/rfid/scan
Method: POST
Auth: Bearer TOKEN
```

### Pistola RFID (Exemplo: Zebra MC3300R)

**App Android:**

- SDK: Zebra RFID SDK 3
- API: RFIDReader.Events.readEvent
- Modo: Trigger scan
- Buffer: 100 tags
- Auto-submit via HTTP

## TROUBLESHOOTING

### NFC não funciona no celular

- Verificar se NFC está ativado (Configurações)
- Aproximar parte traseira do celular da tag
- Tag pode estar danificada (testar outra)
- Navegador não suporta (usar Chrome Android)

### RFID não lê equipamento

- Verificar se tag está na orientação correta
- Aumentar potência do leitor
- Verificar interferências metálicas
- Tag pode estar danificada (RSSI muito baixo)

### Portal não envia dados

- Verificar conexão de rede
- Testar endpoint manualmente (Postman)
- Verificar token de autenticação
- Checar logs do leitor
